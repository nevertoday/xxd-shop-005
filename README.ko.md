**뷰티·스킨케어 상품을, 밝고 정돈되고 실제 생활 같은 집 안에서 찍은 것처럼.**
진짜 카메라로 찍은 일상의 느낌이지만 취향 좋은 사람의 집처럼 깔끔하고, 상품이 화면에서 가장 밝고 선명합니다.

| 한눈에 보기 | |
|---|---|
| **맡기는 것** | 상품 이미지(권장) 또는 상품명, 그리고 "아침 세럼", "욕실 바디로션" 같은 용도 한마디 |
| **받는 것** | 샤오훙수풍 라이프스타일 컷과 스토어 장면 이미지. 한 집에서 찍은 캐러셀 세트도 |
| **스타일 특징** | 하이키 자연광 · 어두운 구석이나 짙은 그림자 없음 · 적고 정돈된 소품 · 도자기 접시, 돌 트레이, 깨끗한 상판 · 기본은 글자 없음 |
| **가장 잘 맞는 곳** | 뷰티, 스킨케어, 퍼스널케어, 향수의 라이프스타일 컷과 장면 이미지 |

## 해결하는 문제

뷰티 라이프스타일 이미지는 두 가지로 실패합니다. 너무 스튜디오 같아서 광고로 읽히거나, "자연스럽게"가 지저분해져 어수선한 세면대와 반사에 묻힌 라벨이 됩니다.

**Shop 005**는 그 사이를 걷습니다. **진짜 카메라의 일상감, 취향 좋은 사람의 집 같은 정돈감.** 하이키 실내 자연광이 공간을 채우고 어두운 구석도 짙은 그림자도 없습니다. 소품은 적고 반듯하게 놓이며, 상품은 도자기 접시나 돌 트레이, 깨끗한 면 위에서 화면에서 가장 밝고 온전하고 잘 읽히는 존재가 됩니다.

## 다른 스타일과 다른 점

- **글자 없음.** 포스터가 아니라 사진입니다. 기본적으로 타이틀도 스티커도 없고, 글자에 대해 묻지도 않습니다.
- **밝음.** 넓은 어두운 영역, 검은 배경, 강한 측광을 쓰지 않습니다. 어두운 고급스러움이 필요하면 [001](https://github.com/nevertoday/xxd-shop-001)이나 011이 더 맞습니다.

## 캐러셀

캐러셀을 요청하면(기본 4장, 3~6장 가능) 같은 깨끗한 집의 여러 구석이 나옵니다. 도자기 접시, 돌 트레이, 수납장, 화장대 거울 앞… 장마다 놓이는 면이나 거리를 바꾸되 빛과 재질은 한 집 그대로입니다. 마지막 장은 거리를 바꿔 첫 장의 자리로 돌아와 캐러셀이 순환합니다.

## 준비할 것

- **상품 이미지**(권장): 흰 배경이든 실물 사진이든. 병의 글자, 로고, 라벨을 그대로 지킵니다. 라벨의 작은 글자에는 정면에서 또렷하게 찍은 한 장이 가장 중요합니다.
- **또는 상품명:** 이름만으로도 만들 수 있습니다.
- **용도**(권장): "아침 세럼", "욕실 바디로션" 등. 장면과 소품이 이를 따릅니다.

## 사용 방법

### 1단계: 설치 (한 번만)

```bash
git clone https://github.com/nevertoday/xxd-shop-005.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-005" ~/.claude/skills/xxd-shop-005
```

Codex 사용자는 같은 폴더를 `~/.codex/skills/xxd-shop-005`에 링크하세요. 설치 후에는 AI 어시스턴트 세션을 다시 시작합니다.

### 2단계: 원하는 것을 평소 말로 말하기

```text
/xxd-shop-005 이 나이아신아마이드 세럼으로 라이프스타일 컷을 만들어 줘
/xxd-shop-005 샴푸와 핸드크림을 나란히, 각자 다른 장면으로, 3:2
/xxd-shop-005 이 세럼으로 4장짜리 캐러셀을 만들어 줘
```

외울 플래그는 없습니다. 사이즈나 장수처럼 정하지 않은 것은 한 번에 모아서 묻고, 다음에는 지난 설정을 다시 쓸 수 있습니다.

### 3단계: 그다음에 하는 일

1. 상품 이미지와 설명을 읽고 아직 정해지지 않은 것만 묻습니다. 사이즈는 용도에 맞춰 픽셀 크기와 함께 추천합니다.
2. 이 스타일은 기본적으로 글자를 넣지 않고, 글자에 대해 묻지도 않습니다.

## 자주 묻는 질문

**어떤 사이즈를 써야 하나요?**

샤오훙수는 3:4, 스토어 장면 이미지는 1:1, 두 상품을 나란히 두려면 3:2.

**이미지에 효능을 쓰나요?**

아니요. 글자는 상품 패키지에 원래 있는 것뿐입니다.

**무엇이 필요한가요?**

세 가지입니다. ① Claude Code나 Codex처럼 Skills를 지원하는 AI 어시스턴트. ② 이미지를 생성할 수 있는 모델: 어시스턴트에 내장된 이미지 생성, 또는 Codex에 설정한 모델 제공자로 Responses API를 통해 이미지를 생성하는 것(기본 GPT Image 2). ③ Pillow가 설치된 Python 3.11 이상(`pip install pillow`).

**비용이 드나요? 상업적으로 써도 되나요?**

Skill은 무료로 내려받을 수 있고, 이미지 생성 비용은 본인의 모델 계정에 청구됩니다. 이 프로젝트는 PolyForm Noncommercial 라이선스입니다. 개인 학습·연구·테스트는 괜찮지만, 쇼핑몰 운영, 외주 납품 등 상업적 사용은 먼저 작성자의 서면 허가가 필요합니다. 맨 아래 "라이선스"를 참고하세요.

**이미지는 얼마나 큰가요?**

비율이나 정확한 픽셀을 요청할 수 있습니다. 실제 크기는 모델이 돌려준 그대로이며 몰래 업스케일하지 않고, 파일 이름에 실제 픽셀이 적힙니다.

**이미지 속 글자에 오타가 생기나요?**

AI 이미지는 가끔 철자를 틀리거나 브랜드 이름 옆에 ® 같은 작은 기호를 덧붙입니다. 납품 전에 한 장씩 확대해 확인하고, 통과하지 못하면 다시 만듭니다. 이 페이지의 예시는 모두 그 확인을 통과했습니다.

**가격이나 판매량을 지어내나요?**

아니요. 가격, 사양, 원산지, 판매량, 수상, 인증처럼 사실로 보이는 것은 내가 준 것이나 상품에서 또렷이 읽히는 글자에서만 가져옵니다. 그 밖에는 넣지 않으며 "¥XX" 자리표시도 없습니다.

**상품 여러 개를 한 번에 처리할 수 있나요?**

네. 상품 이미지 폴더를 주세요. 이미지 하나에 상품 하나, 사이즈와 글자는 한 번만 묻고, 한 상품의 사실이나 문구가 다른 상품으로 새지 않습니다.
