# 🦁 XXD Shop 005｜明亮美妆场景

### 收拾得很干净的家里，随手拍到的那一瓶

**把美妆护肤品放进一个明亮、干净、像真实生活的家里拍一张。**
真实相机的生活感，但整洁得像审美很好的人家里；产品是画面里最亮、字最清楚的东西。

| 一眼看懂 | |
|---|---|
| **交给它** | 产品图（推荐）或产品名，加一句用途，比如“晨间精华”“浴室身体乳” |
| **你拿到** | 小红书种草图、电商场景图；也能一次出一组同一个家里的轮播图 |

## 它解决什么

美妆种草图有两种常见的失败：一种是棚拍感太重，像广告不像生活；另一种是“随手拍”拍成了杂乱，桌上东西一堆，瓶子上的字被反光吃掉。

**Shop 005** 要的是中间那条线：**真实相机的生活感，但整洁得像审美很好的人家里。** 高调的室内自然光把空间照透，没有暗角和重阴影；道具少，横平竖直；产品放在陶盘、石托或干净台面上，是画面里最亮、最完整、字最清楚的东西。

## 和别的款有什么不同

- **没有文字。** 这是一张照片，不是海报，默认不加任何标题或贴纸，也不会问你文字的事。
- **亮。** 这套风格明确排斥大面积暗部、黑背景和强侧光；想要高级暗调，用 [001](https://github.com/nevertoday/xxd-shop-001) 或 011 更合适。

## 种草轮播

说“做一组轮播”（默认 4 张，可以 3–6 张），就是同一个干净的家里的几处角落：陶盘、石材托盘、收纳柜、梳妆镜前……每张换一个摆放处或远近，光和材质都是同一个家的。最后一张回到第 1 张的位置、换一个远近，让轮播首尾相接。

## 你需要准备

- **产品图**（推荐）：白底图或实拍图都行，瓶身文字、Logo、标签会照着保留。标签字小的产品，给一张正面清楚的图最要紧。
- **或者产品名**：没有图也能按名字生成。
- **用途**（推荐）：“晨间精华”“浴室身体乳”，场景和道具会跟着用途走。

## 怎么用

### 第一步：安装（只需一次）

```bash
git clone https://github.com/nevertoday/xxd-shop-005.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-005" ~/.claude/skills/xxd-shop-005
```

Codex 用户把同一个文件夹链接到 `~/.codex/skills/xxd-shop-005`。装好后重开一次 AI 助手的会话。

### 第二步：用大白话说出你要什么

```text
/xxd-shop-005 这瓶烟酰胺精华做一张小红书种草图
/xxd-shop-005 洗发水和护手霜左右并排，各自一个场景，3:2
/xxd-shop-005 这瓶精华做一组 4 张的种草轮播
```

不用记参数。没说清的事（比如尺寸、张数），它会一次问齐；第二次用时可以直接沿用上次的设置。

### 第三步：它会这样做

1. 看你的商品图和描述，只问还没定的事；尺寸会按用途推荐比例，并告诉你像素。
2. 这款默认不加文字，不会问文字方式。
3. 做轮播时，先给你看分镜和第 1 张，你确认后再出其余几张。
4. 每个尺寸都重新构图，不是从一张图裁出来的。
5. 交付前逐张检查：商品有没有被改、字有没有写错、有没有多出你没给的数字。不通过的会告诉你并重做。
6. PNG 存进 `~/Desktop/xxd/xxd-shop-005/` 下新建的任务文件夹，把路径告诉你。

## 常见问题

**什么尺寸合适？**

小红书用 3:4，电商场景图用 1:1，双品并排用 3:2。

**会在图上写功效吗？**

不会。画面里只有产品本身的包装文字。

**需要什么才能用？**

三样东西：① 一个支持 Skills 的 AI 助手，比如 Claude Code 或 Codex；② 一个能出图的模型，可以是助手自带的出图能力，也可以是在 Codex 里配置好的、通过 Responses 接口出图的模型供应商（默认用 GPT Image 2）；③ 电脑上装有 Python 3.11 以上和 Pillow（`pip install pillow`）。

**要花钱吗？能商用吗？**

Skill 本身免费下载，出图费用由你自己的模型账户承担。本项目采用 PolyForm 非商业许可：个人学习、研究、测试可以直接用；用于店铺经营、接单交付等商业用途，需要先取得作者的书面授权，见文末“许可证”。

**出来的图有多大？**

你可以指定比例或准确像素。实际像素以模型返回为准，不会偷偷放大冒充高清，文件名里写的就是真实像素。

**图里的字会写错吗？**

AI 出图偶尔会写错字，或在品牌名旁多出 ® 这类小符号。交付前会逐张放大检查，发现问题就重做那一张；本页的样张都过了这一步。

**会不会乱写价格、销量？**

不会。画面上像事实的内容（价格、规格、产地、销量、获奖、认证……）只来自你提供的信息或商品图上看得清的字；没给就不写，也不放“¥XX”这种占位。

**能一次处理很多商品吗？**

能。把商品图文件夹交给它，每张图当作一件商品，尺寸和文字设置只问一次；每件商品的信息和文案互不串用。

## 它的原则

- **风格不走样：** 这款背后是一份成熟的商业设计提示词（[设计原文](references/original-prompt/zh-CN.md) · [English](references/original-prompt/en.md)）。Skill 不改写它，也不另加配色和美术指导，只把你的商品、尺寸、文字和事实交给模型。
- **商品不改款：** 有商品图时，造型、颜色、包装文字和 Logo 以图为准。
- **只用你给的事实，** 每件商品各管各的，不借用别的商品、旧成品或样张里的内容。
- **交付真实的 PNG 位图，** 不用 SVG 或代码绘图冒充；每次调用都新建任务文件夹。
- 瓶身文字和 Logo 不改写、不乱码。
