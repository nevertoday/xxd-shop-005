# 🦁 XXD Shop 005｜明るいコスメのシーン写真

### きれいに片づいた家で、何気なく撮れたあの1本

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <strong>日本語</strong> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md">العربية</a>

</div>

**コスメやスキンケア商品を、明るく片づいた、暮らしのリアルな家の中で撮影したように。**
本物のカメラで撮った日常感、でもセンスのいい人の家のように整っていて、商品が画面でいちばん明るく、くっきりしています。

| ひと目で分かる | |
|---|---|
| **渡すもの** | 商品画像（推奨）または商品名と、「朝の美容液」「バスルームのボディローション」のような用途のひと言 |
| **受け取るもの** | 小紅書（RED）風のライフスタイル写真や、ストアのシーン画像。同じ家で撮ったカルーセルセットも |
| **スタイルの特徴** | ハイキーな自然光 · 暗い隅や重い影なし · 少なく整った小物 · 陶器の皿、石のトレー、きれいな天板 · 既定では文字なし |
| **向いている用途** | コスメ、スキンケア、パーソナルケア、フレグランスのライフスタイル写真とシーン画像 |

> **インストールしたら、こう言うだけ：**
>
> /xxd-shop-005 このナイアシンアミド美容液のライフスタイル写真を作って

## 解決すること

コスメのライフスタイル画像の失敗は2通り。スタジオっぽすぎて広告に見えるか、「自然に」が散らかって、ごちゃついた洗面台と反射で読めないラベルになるか。

**Shop 005** はその間を歩きます。**本物のカメラで撮った日常感、センスのいい人の家のような整い方。** ハイキーな室内の自然光が空間を満たし、暗い隅も重い影もありません。小物は少なく、きちんと並べ、商品は陶器の皿や石のトレー、きれいな面の上に置かれ、画面でいちばん明るく、欠けがなく、読みやすい存在になります。

## ほかのスタイルとの違い

- **文字なし。** これはポスターではなく写真です。既定ではタイトルもステッカーもなく、文字について質問もしません。
- **明るい。** 大きな暗部、黒背景、硬いサイド光は使いません。暗めの上質感がほしいなら [001](https://github.com/nevertoday/xxd-shop-001) か 011 が向いています。

## カルーセル

カルーセルを頼むと（既定は4枚、3〜6枚まで）、同じきれいな家のいくつもの片隅が撮れます。陶器の皿、石のトレー、収納棚、ドレッサーの鏡の前…。1枚ごとに置き場所や距離を変え、光と素材はひとつの家のまま。最後の1枚は距離を変えて最初の場所に戻り、カルーセルがループします。

## 用意するもの

- **商品画像**（推奨）：白背景でも実物写真でも。ボトルの文字、ロゴ、ラベルはそのまま残します。ラベルの小さな文字には、正面からのはっきりした1枚がいちばん大事です。
- **または商品名：** 名前だけでも作れます。
- **用途**（推奨）：「朝の美容液」「バスルームのボディローション」など。シーンと小物がこれに沿います。

## 使い方

### ステップ 1：インストール（1回だけ）

```bash
git clone https://github.com/nevertoday/xxd-shop-005.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-005" ~/.claude/skills/xxd-shop-005
```

Codex を使う場合は、同じフォルダを `~/.codex/skills/xxd-shop-005` にリンクしてください。インストール後は AI アシスタントのセッションを再起動します。

### ステップ 2：やりたいことを普通の言葉で言う

```text
/xxd-shop-005 このナイアシンアミド美容液のライフスタイル写真を作って
/xxd-shop-005 シャンプーとハンドクリームを並べて、それぞれ別のシーンで、3:2
/xxd-shop-005 この美容液で4枚のカルーセルを作って
```

覚えるフラグはありません。サイズや枚数など決めていないことは一度にまとめて質問され、次回は前回の設定を再利用できます。

### ステップ 3：そのあと何をするか

1. 商品画像と説明を読み、まだ決まっていないことだけを質問します。サイズは用途から、ピクセル数付きで提案します。
2. このスタイルは既定で文字を加えず、文字について質問もしません。
3. カルーセルでは、まず絵コンテと1枚目を見てもらい、確認のあとで残りを作ります。
4. サイズごとに構図を新しく作り、別の画像から切り抜くことはありません。
5. 納品前に1枚ずつ確認します。商品は変わっていないか、文字のつづりは正しいか、渡していない数字はないか。通らないものは報告して作り直します。
6. PNG を `~/Desktop/xxd/xxd-shop-005/` の下の新しいタスクフォルダに保存し、パスを伝えます。

## よくある質問

**どのサイズを使えばいいですか？**

小紅書は 3:4、ストアのシーン画像は 1:1、2つの商品を並べるなら 3:2。

**画像に効能を書きますか？**

いいえ。文字は商品のパッケージに元からあるものだけです。

**何が必要ですか？**

3つです。① Claude Code や Codex など、Skills に対応した AI アシスタント。② 画像を生成できるモデル。アシスタント内蔵の画像生成、または Codex に設定したモデルプロバイダーで Responses API 経由で画像を生成するもの（既定は GPT Image 2）。③ Pillow 入りの Python 3.11 以上（`pip install pillow`）。

**お金はかかりますか？商用利用できますか？**

Skill は無料でダウンロードできます。画像生成の費用はあなた自身のモデルアカウントに請求されます。本プロジェクトは PolyForm Noncommercial ライセンスです。個人の学習・研究・テストには使えますが、ショップ運営、受託制作などの商用利用には事前に作者の書面による許可が必要です。末尾の「ライセンス」を参照してください。

**画像の大きさは？**

比率か正確なピクセル数を指定できます。実際のサイズはモデルが返したとおりで、こっそり拡大することはなく、ファイル名に本当のピクセル数が書かれます。

**画像内の文字に誤字は出ますか？**

AI の画像では、ときどき文字を間違えたり、ブランド名の横に ® のような小さな記号を足したりします。納品前に1枚ずつ拡大して確認し、通らないものは作り直します。このページの作例はすべてその確認を通っています。

**価格や販売数をでっち上げませんか？**

しません。価格、仕様、産地、販売数、受賞、認証など事実に見えるものは、あなたが提供したものか、商品にはっきり読める文字からだけ取ります。それ以外は載せず、「¥XX」の仮置きもしません。

**たくさんの商品を一度に処理できますか？**

できます。商品画像のフォルダを渡してください。1枚の画像に商品1つ、サイズと文字は一度だけ質問され、ある商品の事実やコピーが別の商品に混ざることはありません。

## 原則

- **スタイルは忠実に：** この Skill の背後には成熟した商業デザインのプロンプトがあります（[原文プロンプト](references/original-prompt/zh-CN.md) · [英語の参考訳](references/original-prompt/en.md)）。Skill はそれを書き換えたり、独自の色やアートディレクションを足したりせず、あなたの商品、サイズ、文字、事実をモデルに渡すだけです。
- **商品をデザインし直さない：** 商品画像があれば、形、色、パッケージの文字、ロゴは写真どおりです。
- **あなたの事実だけ、** そして商品はそれぞれ独立。ほかの商品、以前の結果、作例から何も借りません。
- **本物の PNG ビットマップ。** SVG やコードで描いた絵を画像として出すことはなく、実行のたびに新しいタスクフォルダを作ります。
- ボトルの文字やロゴを書き換えたり崩したりしません。
