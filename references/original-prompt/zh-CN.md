# Original XXD Shop 005 style brief

为当前美妆产品生成明亮、干净、规整、有生活质感的电商场景图。

若用户提供白底产品图或实拍图，严格保留原产品造型、比例、包装颜色、Logo、标签、瓶身材质与关键识别特征，不重新设计商品；只重建与新环境一致的光线、阴影、反射和空间关系，使产品真实自然地存在于场景中。

画面第一要求是“主体一眼清楚”。产品处于最明确、最明亮、最完整的视觉位置，轮廓干净，瓶身文字尽可能清晰，不能被道具、阴影、反光或复杂背景干扰。

整体采用高调明亮的室内自然光感。空间被柔和漫射光充分照亮，不出现大面积黑区、沉重暗角、强烈明暗切割或压抑阴影。阴影只用于表现商品落地与体积，应浅、软、干净；白色、奶油色、浅木色、浅灰、柔和品牌色之间通过轻微明度和材质差异建立层次，而不是依靠深色制造对比。

背景保持简洁、有秩序、有呼吸感。道具数量主动克制，只选择少量与产品气质匹配的物件，例如规整收纳柜、简洁托盘、玻璃罐、镜框、折叠织物、金属置物架、花朵或书籍。所有道具轮廓尽量简洁，保持清晰的水平、垂直和层次关系，不随机散落，不制造凌乱生活痕迹。

商品可以自然放置在浅色陶盘、石材托盘、干净桌面或简洁收纳区域中，让承载面稳定、完整、规整。背景物体负责形成空间层次，但始终退后，不包围商品，不抢主体。

构图偏稳定、舒服、清楚，可以居中或轻微偏心，但整体保持视觉平衡。避免过多斜线、复杂遮挡、前景虚化物、大量散落小物以及故意制造“随手乱拍”的感觉。画面像一个审美很好、收拾得很干净的人家中自然拍到的美妆照片。

色彩整体轻盈、柔和、正面，白色与浅色区域保持通透，不发灰、不发黄、不脏。产品自身颜色可以成为画面的主要色彩记忆，其余环境安静配合。

最终效果：主体清楚、背景简单、空间明亮、道具规整、层次柔和，真实相机拍摄感，干净治愈但不过度奶油滤镜，适合小红书 PLOG、美妆种草、电商场景图。

避免：大面积暗部、黑色背景、强烈侧光、重阴影、暗角、杂乱道具、随机散落、复杂遮挡、凌乱前景、过度复古滤镜、过多装饰、背景信息量过高。
